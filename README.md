<h1>H0B0fetch</h1>

<h2>Описнаие</h2>

H0B0fetch является как мне известно моей разработкой
Был создан он из-за того, что нельзя было создавать собственные арты.
Данный код берет из указанной вами папки случайный арт, и показывает вам его вместе с информацией о вашей системе. В общем как обычный фетчер

<h2>Инструкция</h2>

1) Создайте директорию, в которой будете хранить картинки ASCII формата
2) На ~10 строчке кода вам надо будет написать путь к этой директории из которой будут выбираться картинки
3) Для того, чтобы делать картинки цветными, используйте ANSI-escape коды
